■ツール名：
グラフ化ツール+α

----------------------------------------------------------------------------------------------------------------------------

■ツール概要：
渡辺研究室にある半導体パラメータアナライザ Agilent 4155Cを用いて測定した際に出力されるエクセルデータ（特に電圧-電流特性のデータ）を読み込み、グラフ化・分析・整理するための多機能ツールです。

エクセル上でグラフ化する場合、電流値を電流密度に変換・グラフの体裁を整える、特定の回数だけ表示させるのに時間がかかり、非常に手間がかかりました。それらの手間を省くために本ツールを開発しました。

またこのツールは生成AIであるGeminiと共に作りました。

----------------------------------------------------------------------------------------------------------------------------

■起動する前に：
本ツールを使うにはパイソン環境が必要です。

また、このプログラムを動かすために、お使いのPython環境にいくつかの追加ライブラリをインストールする必要があります。
・pandas: データの読み込み、処理、操作（pd）に使用されます。
・matplotlib: グラフの描画（plt）に使用されます。
・openpyxl: pandasが.xlsx形式のExcelファイルを読み書きするために必要です。
・xlrd: pandasが古い.xls形式のExcelファイルを読み込むために必要です。

ターミナル（またはコマンドプロンプト）で以下のコマンドを実行してください。
pip install pandas matplotlib openpyxl xlrd

■ツール選択：
起動すると、まずツール選択ウィンドウが表示されます。ここで、行いたい作業を選びます。

① グラフ化ツール:

目的: Excelシートのデータを1つずつグラフで確認することができます。特性の分類や整理については現在開発中です。

主な機能: グラフ描画（分類、分類結果のExcelファイル出力は現在開発中)


② Vpeak/Jpeak ばらつき比較ツール(現在開発中):


③ Excel統合ツール:

目的: x1y1, x1y2 のような名前のシートを、複数のExcelファイルから探し出し、1つの新しいExcelファイルにまとめるためのツールです。

主な機能: 複数のExcelファイルの統合。

----------------------------------------------------------------------------------------------------------------------------

・読み込みモードについて

①一括読み込み:

動作: 起動時にExcelファイルの全データを先に読み込みます。

長所: 起動後はシートの切り替えが高速です。

短所: 起動に時間がかかります（特にファイルが大きい場合）。


②都度読み込み:

動作: 起動は速く、シートを切り替えるたびにデータを読み込みます。

長所: 起動が高速です。

短所: シートの切り替えに毎回少し時間がかかります。

(ファイルが極端に大きくなければ一括読み込みが快適です)

----------------------------------------------------------------------------------------------------------------------------

■各ツールの使い方

① グラフ化ツールの使い方
１,ファイル選択: グラフ化ツールボタンを押すと、ファイル選択ダイアログが開くので、分析したいExcelファイルを選びます。

２,直径の入力: 次に、デバイスの「直径 (nm)」を入力する画面が出ます。生の電流値 [A] を電流密度 [MA/cm²] に正しく換算します。SEMで観察した直径値を入力してください。100nm パターン), 2µm パターン, 500nm パターン の直径をそれぞれ入力します。

３,操作画面: グラフが表示される「グラフ表示」ウィンドウと、「コントロールパネル」の2つが開きます。

４,グラフの確認:
・コントロールパネルの「シート」欄で、見たいシート（サンプル）をドロップダウンリストから選ぶか、<>ボタンで切り替えます。
・グラフは自動で更新されます。

５,結果の保存:
グラフを保存: 今見ているグラフだけを画像 (PNGなど) で保存します。


②Vpeak/Jpeak ばらつき比較ツール (開発中)

③Excel統合ツール の使い方
１,Excel統合ツールボタンを押します。

２,ファイル選択: このツールは、シート名が x1y1 x1y2 x2y1 ... のような「座標」形式になっているものだけを対象とします。まとめたいExcelファイルを複数選択します。

３,保存先を指定: 統合したデータを保存する、新しいExcelファイルの名前と場所を決めます。

４,プログラムが、選んだ全てのファイルから x〇y〇 形式のシートを探し出し、x1y1, x1y2... の順に並べ替えて、1つの新しいExcelファイルに書き出します。

----------------------------------------------------------------------------------------------------------------------------

■その他の機能
・グラフのホバー: グラフの線の上にマウスカーソルを合わせると、その点の詳細な値（電圧、電流、電流密度）が小さなウィンドウで表示されます。

・コントロールパネルの調整: 「グラフ化ツール」「Vpeakツール」のコントロールパネルでは、フォントサイズ、線の太さ、凡例の表示/非表示、軸の範囲などを細かく調整してグラフを更新できます。

・レイアウト変更: コントロールパネルが縦に長すぎるときは、上部の2列レイアウトで表示のチェックを外すと、1列表示に切り替わります。
